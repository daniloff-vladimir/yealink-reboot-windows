# Yealink Device Reboot Tool

Windows batch-скрипт для массовой перезагрузки устройств Yealink через веб-интерфейс.

## 📋 Описание

Этот скрипт позволяет удаленно перезагружать несколько устройств Yealink (IP-телефоны, видеоконференции и др.) путем отправки команды перезагрузки через HTTP-запрос к веб-интерфейсу устройства.

## ✨ Особенности

- Поддержка множественных IP-адресов
- Простой текстовый интерфейс
- Автоматическая обработка ошибок
- Подсчет статистики выполнения
- Поддержка русского языка (UTF-8)

## 🚀 Использование

### Требования
- Windows ОС
- Утилита `curl` (должна быть доступна в PATH)
- Сетевой доступ к устройствам Yealink
- Включить на телефоне Action URI (https://habr.com/ru/companies/ipmatika/articles/716476/)

### Запуск
1. Скачайте файл `yealink_reboot.bat`
2. Запустите двойным кликом или через командную строку
3. Следуйте инструкциям на экране

### Формат ввода IP-адресов
Введите IP-адреса через пробел или запятую:

**Пример с запятыми:**
```
10.0.6.103, 10.0.6.104, 10.0.6.105
```

**Пример с пробелами:**
```
10.0.6.103 10.0.6.104 10.0.6.105
```

## ⚙️ Принцип работы

Скрипт отправляет HTTP-запрос на каждый указанный IP-адрес по адресу:
```
https://admin:admin@IP_ADDRESS/servlet?key=Reboot
```

### Учетные данные по умолчанию
- **Логин:** `admin`
- **Пароль:** `admin`

> ⚠️ **Внимание:** Если на ваших устройствах установлены другие учетные данные, необходимо изменить скрипт.

## 🔧 Настройка

Если на ваших устройствах Yealink установлены другие учетные данные, отредактируйте строку с curl-запросом:

```batch
curl --insecure --connect-timeout 3 --max-time 5 --silent "https://USERNAME:PASSWORD@%%i/servlet?key=Reboot" >nul 2>&1
```

Замените `USERNAME` и `PASSWORD` на актуальные значения.

## 📊 Выходные данные

Скрипт отображает:
- Прогресс выполнения для каждого устройства
- Общее количество обработанных устройств
- Количество успешных операций
- Рекомендации по проверке состояния

## ⏱️ Время выполнения

После отправки команды устройства начинают перезагрузку. Рекомендуется проверить физическое состояние устройств через **2-3 минуты**.

## 🔒 Безопасность

- Скрипт использует флаг `--insecure` для обхода проверки SSL-сертификатов
- Таймаут соединения установлен на 3 секунды
- Максимальное время выполнения запроса - 5 секунд

## ❗ Ограничения

- Работает только с устройствами Yealink
- Требует стандартные учетные данные или ручное изменение скрипта
- Не проверяет фактический результат перезагрузки, только факт отправки команды

## 🐛 Устранение неисправностей

Если скрипт не работает:
1. Проверьте доступность устройств по сети (ping)
2. Убедитесь, что curl установлен и доступен в PATH
3. Проверьте учетные данные устройства
4. Убедитесь, что веб-интерфейс устройства доступен

## 📄 Лицензия
